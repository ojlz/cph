# Site Completo para Sua Loja — Proposta

> Site profissional com cardápio online, carrinho de compras, pedidos via WhatsApp e painel administrativo completo.
> Pronto para usar. Personalizável. Funciona no celular.

---

## O que o site entrega

### Para o Cliente (quem compra)

| Funcionalidade | Descrição |
|---|---|
| **Home com Destaques** | Produtos em evidência na página inicial com fotos, preços e botão de adicionar ao carrinho |
| **Cardápio Completo** | Todos os produtos organizados por categorias (Pastéis, Hambúrgueres, Bebidas...) com abas de navegação |
| **Carrinho de Compras** | Adicionar e remover itens, escolher tamanhos (Normal, Pastelão), aplicar cupom de desconto |
| **Promoções Visíveis** | Produtos em oferta aparecem com preço antigo riscado e novo preço em destaque |
| **Pedido via WhatsApp** | Preenche nome, endereço (entrega) ou retirada, pagamento. Tudo vai pro WhatsApp como mensagem organizada |
| **Formulário de Contato** | Envia mensagem com avaliação, sugestão ou crítica — vai direto pro painel admin |
| **Informações da Loja** | WhatsApp, Instagram, telefone, endereço, horários com indicador "Aberto agora" |
| **Política de Privacidade** | Página completa conforme LGPD |
| **Responsivo** | Funciona perfeitamente no celular, tablet e computador |

### Para o Dono (painel admin)

| Funcionalidade | Descrição |
|---|---|
| **Dashboard** | Visão geral: visitas hoje/total, ações dos clientes, pedidos recebidos |
| **Produtos** | Adicionar, editar, excluir. Nome, descrição, preço, variações de tamanho, imagem, disponível/destaque |
| **Categorias** | Ordenar, renomear, adicionar ou remover categorias do cardápio |
| **Pedidos** | Lista completa com ID único (#ORD-2407-XXXX). Buscar por nome ou número. Confirmar ou cancelar. Ver detalhes |
| **Promoções e Cupons** | Criar desconto direto (ex: de R$20 por R$10) ou cupom percentual (ex: CUPOM10 = 10% off). Definir validade |
| **Mensagens** | Mensagens recebidas do formulário de contato. Buscar, expandir e ler |
| **Horários** | Configurar dia por dia: aberto/fechado, horário único ou dois turnos |
| **Configurações** | Nome, slogan, WhatsApp, Instagram, telefone, endereço da empresa |
| **Senha** | Alterar a senha de acesso ao painel |
| **Tudo pelo celular** | O painel admin é adaptado pra funcionar no celular — hamburger menu, cards responsivos |

## Segurança (diferencial)

1. Quando o cliente faz um pedido, o servidor valida cada preço no banco de dados
2. O pedido é salvo automaticamente com um número único (#ORD-...)
3. A mensagem vai pro WhatsApp da loja com o número do pedido
4. A atendente abre o painel admin, busca o número e confere os valores reais

**Mesmo que o cliente edite a mensagem no WhatsApp, não adianta — o pedido verdadeiro já está salvo no servidor.**

Todas as APIs têm limite de requisições por IP (anti-spam). Senha do admin com criptografia bcrypt.
